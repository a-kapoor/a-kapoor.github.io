Vector Embeddings

Words become points in space — similar meanings land close together.

Hover over a word to see distances. Click two words to compare.
What's happening? Each word is encoded as a short vector of numbers (here just 2-D for visualisation). Two words that are semantically similar (e.g. "cat" & "dog") get vectors that point in nearly the same direction, so they appear close together. The cosine similarity measures the angle between two vectors: 1 = identical direction, 0 = unrelated. This is the core idea behind word2vec, GloVe, and modern LLM embeddings.

Tiny Transformer

Click words to build your prompt:

your prompt appears here…

1 · Embeddings

Each word → a vector of numbers

2 · Attention

How much each word attends to every other

3 · Prediction

Softmax probabilities for next word

What's happening? This is a drastically simplified transformer with hand-tuned weights on a tiny vocabulary. The real steps are the same: (1) Embed each input token as a vector; (2) Compute self-attention — each token asks "how relevant is every other token to me?" via dot-product scores, then softmax; (3) The context-weighted vectors are projected to produce a probability distribution over the vocabulary — the highest-probability word is the prediction. Real models (GPT, etc.) stack many such layers and use billions of learned parameters, but the core loop is exactly this.

Convolution

Apply a filter kernel to an image and see the output feature map.

What's happening? A 3×3 kernel slides across the input image. At each position, we multiply element-wise and sum — that's the convolution. Different kernels extract different features: edges, blur, sharpening. CNNs learn the best kernels for the task.

PCA

See how principal components capture the directions of maximum variance.

What's happening? PCA finds the axes (principal components) along which the data varies the most. PC1 captures the most variance; PC2 the next most. The right panel shows how much variance each component explains. Projecting onto PC1 alone reduces 2-D data to 1-D while keeping maximum information.

What's happening? At each node the tree picks the feature and threshold that best separates the classes (maximum information gain / Gini reduction). Each split adds an axis-aligned boundary. More depth = more splits = finer regions — but risk overfitting with too many.

Backpropagation

Watch gradients flow backward through a network using the chain rule.

Press ▶ to run one forward+backward pass.
What's happening? Backprop computes ∂Loss/∂w for every weight via the chain rule. Green arrows = forward pass (compute output); red arrows = backward pass (compute gradients). Each weight is updated: w ← w − η·∂L/∂w. This is how all neural networks learn.
